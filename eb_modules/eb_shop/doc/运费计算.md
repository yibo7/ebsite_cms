# 运费计算流程

## 一、核心规则

**满额包邮 + 统一运费，两个参数，一个判断。**

在模块的配置中有两项分别代表：

| 参数 | 说明 |
|---|---|
| `free_shipping_threshold` | 包邮门槛 |
| `flat_shipping_fee` | 统一运费 |

```
if (订单金额 >= 包邮门槛) {
    运费 = 0
} else {
    运费 = 统一运费
}
```

**包邮门槛为 0 时，所有订单包邮，统一运费不生效。**


## 二、触发时机

**运费只在结算页调用并显示。**

| 环节 | 是否计算运费 |
|---|---|
| 商品详情页 | 否 |
| 购物车页 | 否 |
| 结算页 | **是** |
| 提交订单 | 是（最后一次计算并锁定） |
| 支付订单 | 否 |


## 三、结算页运费计算

```
1. 商品总价 = Σ(各 SKU 最终单价 × 数量)
2. 运费 = 商品总价 >= 包邮门槛 ? 0 : 统一运费
3. 应付总额 = 商品总价 + 运费
```

**展示内容**：

- 商品总价
- 运费（0 或统一运费）
- 应付总额


## 四、提交订单

提交订单时最后一次计算运费，写入订单快照并锁定：
 

订单生成后运费锁定，支付环节不再重新计算。


## 五、共用函数

```
calculate_shipping(order_amount) → shipping_fee

if (order_amount >= free_shipping_threshold) {
    return 0
} else {
    return flat_shipping_fee
}
```

调用位置：结算页、提交订单。


## 六、一句话总结

**运费只在结算页计算并显示：订单金额 >= 包邮门槛则包邮，否则收统一运费。提交订单时最后一次计算并写入快照，支付环节不再重算。**
