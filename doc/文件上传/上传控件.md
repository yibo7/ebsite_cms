# 上传控件使用

## 通用引用

```html
<link href="/js/webuploader/webuploader.css" type="text/css" rel="stylesheet">
<script type="text/javascript" src="/js/webuploader/webuploader.min.js"></script>
```

## 上传接口返回值

上传成功后，后端返回 JSON，格式如下：

```json
{
  "originalName": "example.png",
  "name": "example.png",
  "url": "/api/file/66c955480912afeaefb48a9d.png",
  "size": 12345,
  "state": "SUCCESS",
  "type": ".png"
}
```

| 字段 | 说明 |
|---|---|
| `url` | **统一格式的文件访问路径**（带后缀），可直接存入数据库，也可直接用于 `<img src="...">` |
| `type` | 文件扩展名（含点），如 `.jpg`、`.png`、`.pdf` |

> 所有上传插件返回的 `url` 都是扁平格式：`/api/file/<file_id>.<ext>`，
> **URL 必须带文件后缀**，不带后缀的请求将返回 404。
> 即使配置了 `FileStorageSubdir`（如 `site_a`），URL 中也不包含子目录。
> 子目录仅用于磁盘/COS 存储层的文件组织，对前端完全透明。

## 一、单图上传

```html

<script type="text/javascript" src="/js/webuploader/webuploaderpic.js"></script>

<input type="hidden" name="small_pic" id="val_small_pic" value="{model.small_pic}" />
<div class='bduploader'>
  <div><div id='list_small_pic' class='uploader-imglist'></div></div>
  <div id='btn_small_pic'>选择图片</div>
</div>
<script>
  InitImgUpload('btn_small_pic','list_small_pic','val_small_pic',80,80,false);
</script>

```

> 上传成功后，`data.url` 自动填入 hidden input，存入数据库的路径格式为
> `/api/file/66c955480912afeaefb48a9d.png`。

## 二、多图上传

```html
<script type="text/javascript" src="/js/webuploader/webuploaderpic.js"></script>

<div class="mb-3">
  <label>{show_name}</label>
  <input type="hidden" name="{name}" id="{name}" value="[[model.{name}]]" />
  <div class='bduploader'>
      <div><div id='imglisttbuUploadImg_{name}' class='uploader-imglist'></div></div>
      <div id='filedatatbuUploadImg_{name}'>选择图片</div>
  </div>
  <script>
      InitImgUpload('filedatatbuUploadImg_{name}','imglisttbuUploadImg_{name}','{name}',80,80,true);
  </script>
</div>

```

> 多图模式下，多个 URL 以英文逗号分隔存入 hidden input：
> `/api/file/66c9...1.png,/api/file/66c9...2.png,/api/file/66c9...3.png`

## 五、模板中显示文件

存入数据库的 URL 是 `/api/file/<file_id>.<ext>` 格式，在模板中直接使用：

```jinja
<!-- 图片 -->
<img src="{{ model.small_pic }}" alt="">

<!-- 文件下载 -->
<a href="{{ model.file_path }}">下载</a>

<!-- 配合 CDN 前缀（如果配置了 cdn_domain） -->
<img src="{{ model.small_pic | cdn_prefix }}" alt="">
```

可选的 CDN 前缀过滤器：

```python
@app.template_filter('cdn_prefix')
def cdn_prefix(url):
    if url and url.startswith('http'):
        return url
    cdn = current_app.config.get('cdn_domain', '')
    return f'{cdn}{url}' if cdn else url
```
