# 自定义搜索系统

CMS 核心提供了通用的全文搜索（搜索 `title` + `info` 字段），但对于特定模块（如商城），往往需要**自定义搜索范围、搜索字段和结果模板**。自定义搜索系统通过信号机制让模块可以无缝覆盖默认搜索行为。

---

## 一、架构概述

```
用户请求 /search.html?k=关键词&t=1
        │
        ▼
   search() 视图 (website/pages/cms_page.py)
        │
        ├─ 1. 构建 ctx 字典
        │    ctx = {"keyword": ..., "page_number": ..., "page_size": ...}
        │
        ├─ 2. 发送 search_prepare 信号
        │    search_prepare.send(ctx)
        │    │
        │    │  ┌─ 模块监听（如 eb_shop）
        │    │  │  判断是否属于自己管辖
        │    │  │  是 → 设置 ctx["query"] 和 ctx["template"]
        │    │  └─ 其他模块 ...
        │    │
        │    ▼
        ├─ 3. ctx 中有 query？
        │    是 → 使用自定义搜索逻辑 + 自定义模板
        │    否 → 使用默认的 search_full() + search.html
        │
        ▼
   render_template(template, key_word=..., data_list=..., pager=...)
```

### 关键设计原则

| 原则 | 说明 |
|------|------|
| **松耦合** | 核心 CMS 不依赖任何模块，模块通过信号介入搜索 |
| **模块自治** | 每个模块决定自己的搜索字段、过滤条件和结果模板 |
| **无冲突** | 模块通过 URL 参数（如 `t=1`）区分是否由自己处理 |
| **默认兜底** | 无模块响应时，降级为标准 `search_full()` 搜索 |

## 二、信号：`search_prepare`

### 2.1 定义位置

`signals/__init__.py`：

```python
search_prepare = my_signals.signal('search-prepare')
```

### 2.2 发送参数

`cms_page.py` 中 `search()` 视图发送信号时传入一个可变字典 `ctx`：

| 键 | 类型 | 说明 |
|----|------|------|
| `keyword` | `str` | 用户输入的关键词（已 `.strip()`） |
| `page_number` | `int` | 当前页码 |
| `page_size` | `int` | 每页条数 |
| `rewrite_rule` | `str` | 分页 URL 重写规则 |

### 2.3 模块需要设置的 ctx 字段

模块监听函数通过修改 `ctx` 字典来控制搜索行为：

| 字段 | 类型 | 必须 | 说明 |
|------|------|------|------|
| `ctx["query"]` | `dict` | **是** | MongoDB 查询条件，存在此字段即触发自定义搜索 |
| `ctx["template"]` | `str` | 否 | 模板名称，默认 `"search.html"` |

## 三、实现自定义搜索

### 3.1 在模块中监听信号

以商城模块（`eb_modules/eb_shop/__init__.py`）为例：

```python
from signals import content_saving, pay_saved_successful, search_prepare

@module_attribute('商城管理系统', ...)
def module_init(app: Flask, model: ModuleInfo):
    # ... 其他初始化 ...
    search_prepare.connect(on_search_prepare)

def on_search_prepare(ctx: dict):
    """商城模块自定义搜索"""
    # 通过 URL 参数判断是否由本模块处理
    t = http_helper.get_prams("t")
    if t is None:
        return  # 不是本模块的搜索
    
    keyword = ctx.get("keyword", "")
    if not keyword:
        return
    
    # 构建查询条件
    ctx["query"] = {
        "class_id": ObjectId("6852498a0a8b42f2df14146e"),
        "$or": [
            {"column_3": {"$regex": keyword, "$options": "i"}},
            {"column_4": {"$regex": keyword, "$options": "i"}},
        ]
    }
    ctx["template"] = "search_product.html"
```

### 3.2 URL 参数约定

模块应通过唯一的 URL 参数来标识"这是本模块触发的搜索"，避免多个模块冲突：

| 模块 | 参数 | 示例 |
|------|------|------|
| 商城 | `t=1`（商品） / `t=2`（文章） | `/search.html?k=鼓芯&t=1` |
| 其他模块 | 自行约定 | `/search.html?k=xxx&module=xxx` |

### 3.3 拆词搜索（推荐）

直接使用 `$regex` 将整个关键词作为单一模式匹配，用户输入多个单词时**无法匹配**（例如搜 "RICOH MPC8003" 时，`$regex` 要求字段同时包含 "RICOH" 和 "MPC8003" 的连续字符串）。

推荐使用**拆词搜索**——将关键词按空白拆分为单词，每个单词独立匹配：

```python
def _build_word_conditions(keyword: str, fields: list) -> dict:
    """
    拆词搜索（AND 逻辑）。
    每个单词必须在至少一个字段中匹配。
    """
    words = [w for w in keyword.split() if w]
    if not words:
        return {}

    if len(words) == 1:
        word = words[0]
        return {
            "$or": [
                {field: {"$regex": re.escape(word), "$options": "i"}}
                for field in fields
            ]
        }

    # 多个单词：$and 确保每个单词都命中
    return {
        "$and": [
            {
                "$or": [
                    {field: {"$regex": re.escape(word), "$options": "i"}}
                    for field in fields
                ]
            }
            for word in words
        ]
    }
```

> **提示**：`re.escape()` 用于转义用户输入中的正则特殊字符，防止 ReDoS 或意外匹配。

### 3.4 完整示例

```python
import re
from bson import ObjectId
from eb_utils import http_helper
from signals import search_prepare

# ── 模块级常量（分类ID根据实际数据调整） ──
_PRODUCT_CLASS_ID = ObjectId("6852498a0a8b42f2df14146e")
_ARTICLE_CLASS_ID = ObjectId("6852685a0a8b42f2df14147b")

def on_search_prepare(ctx: dict):
    t = http_helper.get_prams("t")
    if t is None:
        return

    keyword = ctx.get("keyword", "")
    if not keyword:
        return

    if t == "2":
        # 文章搜索：搜 title + info
        ctx["template"] = "search_article.html"
        query = {"class_id": _ARTICLE_CLASS_ID}
        query.update(_build_word_conditions(keyword, ["title", "info"]))
        ctx["query"] = query
    else:
        # 商品搜索（默认）：搜 column_3 ~ column_6
        ctx["template"] = "search_product.html"
        query = {"class_id": _PRODUCT_CLASS_ID}
        query.update(_build_word_conditions(keyword, [
            "column_3", "column_4", "column_5", "column_6"
        ]))
        ctx["query"] = query
```

## 四、自定义结果模板

### 4.1 模板渲染变量

无论是自定义搜索还是默认搜索，模板均接收以下变量：

| 变量 | 类型 | 说明 |
|------|------|------|
| `key_word` | `str` | 当前搜索关键词 |
| `data_list` | `list[NewsContentModel]` | 搜索结果列表 |
| `pager` | `str` | 分页 HTML |

### 4.2 模板放置位置

自定义模板需要放在**当前主题的 templates 目录**下：

```
website/themes/<当前主题>/templates/search_product.html
website/themes/<当前主题>/templates/search_article.html
```

如果需要在多个主题下生效，需复制到每个主题的 `templates/` 目录。

### 4.3 模板示例（商品搜索）

```html
{% extends 'base_site.html' %}
{% block title %}{{key_word}} - 商品搜索{% endblock %}

{% block content %}
<section class="page-banner">
  <div class="container banner-content">
    <h1>商品搜索：<span>{{ key_word }}</span></h1>

    {# 搜索输入框（方便用户修改关键词） #}
    <form class="banner-search" method="get" action="/search.html"
          style="display:flex;gap:8px;max-width:500px;margin:16px auto 0;">
      <input type="hidden" name="t" value="1">
      <input type="text" name="k" value="{{ key_word }}" placeholder="搜索型号 / 品牌 / 关键词..."
             style="flex:1;padding:8px 14px;border:1px solid #d1d5db;border-radius:6px;">
      <button type="submit" style="padding:8px 20px;background:#2563eb;color:#fff;border:none;border-radius:6px;">搜索</button>
    </form>
  </div>
</section>

<section class="section">
  <div class="container">
    {% if data_list %}
    {% for item in data_list %}
      {# 商品卡片循环 #}
    {% endfor %}
    {% else %}
    <div class="empty-state">
      <h3>找不到与「{{ key_word }}」相关的商品</h3>
    </div>
    {% endif %}
    {{ pager }}
  </div>
</section>
{% endblock %}
```

## 五、搜索入口 URL 参考

| 用途 | URL | 模板 |
|------|-----|------|
| 首页头部搜索 | `/search.html?k=关键词&t=1` | `search_product.html` |
| 文章列表页侧边栏搜索 | `/search.html?k=关键词&t=2` | `search_article.html` |
| 文章详情页侧边栏搜索 | `/search.html?k=关键词&t=2` | `search_article.html` |
| 默认全局搜索 | `/search.html?k=关键词` | `search.html` |

> 首页头部搜索表单已内置隐藏 `<input type="hidden" name="t" value="1">`，
> 文章列表/详情页侧边栏搜索表单内置 `<input type="hidden" name="t" value="2">`。
