# 多语言设置与主题本地化

## 一、概述

系统支持**自动发现多语言**、**URL 路径前缀切换**以及**浏览器语言检测**（auto 模式）。

核心机制：

- `i18n/` 目录下每有一个 `{code}.json` 文件，就自动注册一种语言
- 非默认语言通过 URL 前缀访问，如 `/en/xxx`、`/ja/xxx`
- 默认语言（无前缀）可通过配置指定，也可设为 `auto` 自动检测浏览器语言

## 二、配置文件

### 2.1 设置默认语言

`conf/setting.json`：

```json
{
    "DefaultLang": "zh"
}
```

| 值 | 说明 |
|-----|------|
| `"zh"` | 无前缀时默认显示中文（推荐） |
| `"en"` | 无前缀时默认显示英文 |
| `"auto"` | 根据浏览器 `Accept-Language` 头自动选择，不匹配时回退到第一种可用语言 |

## 三、语言文件

### 3.1 文件位置

```
website/themes/{theme_name}/i18n/
├── zh.json    # 中文
├── en.json    # 英文
└── ja.json    # 日文（示例）
```

系统启动时自动扫描该目录，每个 `.json` 文件注册一种语言。

### 3.2 自描述键

每个语言文件需要定义自身名称，用于语言切换下拉菜单显示：

```json
{
    "_lang_name": "中文",
    "_lang_name_zh": "中文",
    "_lang_name_en": "Chinese",
    "_lang_name_ja": "中国語"
}
```

- `_lang_name`：该语言自身的名称，**所有语言的下拉菜单统一使用此值**（native name）
- `_lang_name_zh` / `_lang_name_en` / `_lang_name_ja`：各语言的显示名称，当前未使用但保留扩展

### 3.3 翻译键命名约定

```
{页面}_{用途}
```

示例：

| 键 | 中文值 | 英文值 |
|-----|--------|--------|
| `nav_home` | 首页 | Home |
| `content_intro` | 乐谱简介 | About This Score |
| `login_btn` | 登录 | Login |
| `search_placeholder` | 曲谱、歌手、制谱师 | Scores, Artists, Creators |

### 3.4 缺键回退

当某个语言的 JSON 文件中缺少某个键时，自动使用**默认语言**（zh）的对应值填充，无需复制全部键。

```json
// ja.json 只需填写需要翻译的部分
{
    "_lang_name": "日本語",
    "nav_home": "ホーム",
    "nav_login": "ログイン"
    // 其他键自动用中文值回退
}
```

## 四、模板中使用

### 4.1 文本翻译

```html
<!-- 标准用法：lang.xxx + 默认值回退 -->
<h3>{{ lang.content_intro or '乐谱简介' }}</h3>
<span>{{ lang.nav_home or '首页' }}</span>
```

### 4.2 URL 前缀

```html
<!-- LANG_PREFIX 自动处理当前语言前缀 -->
<a href="{{ LANG_PREFIX }}/login">登录</a>
<a href="{{ LANG_PREFIX }}/c112p1.html">吉他谱</a>
```

- 当前语言为**默认语言**（如 zh）时，`LANG_PREFIX` 为 `""`
- 当前语言为**非默认语言**（如 en）时，`LANG_PREFIX` 为 `"/en"`

### 4.3 过滤器中本地化 URL

```html
<!-- localize 过滤器：自动给 URL 加语言前缀 -->
<a href="{{ '/a126019.html'|localize }}">链接</a>
```

### 4.4 语言切换下拉菜单

导航栏右侧的切换菜单自动遍历所有可用语言：

```html
{% for code, name in available_langs.items() %}
<li>
  <a class="dropdown-item {% if code == current_lang %}active{% endif %}"
     href="{% if code == default_lang %}{{ request.path }}{% else %}/{{ code }}{{ request.path }}{% endif %}">
    {{ name }}
  </a>
</li>
{% endfor %}
```

- `available_langs`：所有可用语言的 `{code: name}` 字典
- `current_lang`：当前语言代码
- `default_lang`：默认语言代码（由 `set_lang()` 解析后确定）

### 4.5 分类名称翻译

分类名称建议在语言文件中用映射字典维护，避免修改数据库：

```json
// en.json
{
    "class_name_1": "Guitar Tabs",
    "class_name_2": "Piano Scores",
    "class_name_105": "Pop Piano"
}
```

模板中：

```html
{{ lang.get('class_name_' ~ item.id, item.class_name) }}
```

找不到对应翻译时自动回退数据库中的原始分类名。

## 五、模板变量参考

| 变量 | 类型 | 说明 |
|------|------|------|
| `lang` | dict | 当前语言的翻译键值对 |
| `current_lang` | str | 当前语言代码，如 `"zh"`、`"en"` |
| `default_lang` | str | 当前请求的有效默认语言代码 |
| `available_langs` | dict | `{code: name}` 所有可用语言 |
| `LANG_PREFIX` | str | URL 前缀，非默认语言时为 `"/en"` 等 |

## 六、添加新语言

1. 在 `i18n/` 下创建 `{code}.json`（如 `ja.json`）
2. 定义 `_lang_name` 键
3. 填写需要的翻译键（可选，缺失自动回退默认语言）
4. 重启服务器

无需修改任何代码，系统自动发现并注册新语言。

访问方式：

| 路径 | 语言 |
|------|------|
| `/` | 默认语言 |
| `/ja/` | 日文 |
| `/ja/c113p1.html` | 日文分类列表 |

## 七、URL 路由规则

### 7.1 WSGI 中间件

`_LangPrefixWSGIMiddleware` 自动处理所有**非默认语言**的 URL 前缀剥离：

```
请求 /en/c113p1.html
  → 中间件剥离 /en/
  → Flask 路由处理 /c113p1.html
  → set_lang() 检测 ORIG_PATH_INFO 为 /en/
  → g.lang = 'en'
```

### 7.2 set_lang() 执行流程

```
请求进入
  ↓
set_lang() before_request
  ↓
① 检查 URL 是否以 /{code}/ 开头 → 匹配则设置 g.lang
② 无匹配且 DefaultLang=auto → 解析 Accept-Language 头
③ 都不匹配 → 使用配置的默认语言
  ↓
设置 g.lang、g.effective_default、g.lang_dict
```

## 八、缓存注意事项

### 8.1 首页缓存

首页按语言独立缓存，键名前缀包含语言代码：

```
CacheKeys.INDEX_HTML_zh_v2
CacheKeys.INDEX_HTML_en_v2
```

后台缓存线程也会手动设置 `g.lang`，确保模板渲染时语言信息正确。

### 8.2 列表页缓存

```python
cache_key = f"list_data:{id}:{p}:{lang}:v{ver}"
```

列表缓存键也包含语言标记，不同语言版本独立缓存。

## 九、Python 代码中的语言处理

### 9.1 url_links.py

URL 生成函数自动读取当前语言：

```python
from eb_utils import url_links

url_links.get_content_url(a_id)       # → /a123.html 或 /en/a123.html
url_links.get_class_url(c_id)         # → /c1p1.html 或 /en/c1p1.html
url_links.get_url_prefix()            # → "" 或 "/en"
```

### 9.2 mvc_pager.py

分页组件从 `g.lang_dict` 读取按钮文字：

```python
lang_dict = getattr(g, 'lang_dict', {})
first_text = lang_dict.get('list_first', '首页')
prev_text = lang_dict.get('list_prev', '上一页')
```

英文时为 `First` / `Prev`，日文时为 `最初` / `前へ`。

## 十、完整示例

### 添加日语支持

**1. 创建 `ja.json`：**

```json
{
    "_lang_name": "日本語",
    "_lang_name_zh": "日语",
    "_lang_name_en": "Japanese",
    "_lang_name_ja": "日本語",
    "nav_home": "ホーム",
    "nav_login": "ログイン",
    "nav_register": "クリエイター登録",
    "search_placeholder": "楽譜、アーティスト、クリエイター",
    "content_intro": "楽譜紹介",
    "content_chords": "この楽譜のコード",
    "content_related": "関連楽譜"
}
```

**2. 重启服务器**

**3. 访问：**
- `/ja/` → 日文首页
- `/ja/c113p1.html` → 日文列表页

语言切换下拉菜单自动显示"日本語"，点击即可切换。
