# 在 Vercel 上部署

Vercel 提供免费的 Serverless 部署，适合快速体验、演示站或低流量站点。

> ⚠️ Vercel 是无状态平台，**没有文件写入权限**，以下功能受限：
> - 使用 MongoDB 内置缓存（无法使用内存缓存，可改用 Redis）
> - 后台无法更换主题
> - 无法使用「本地文件上传」插件
> - 无法在后台备份数据库

---

## 一、部署前的准备

### 1.1 修改配置

将 `conf/setting.json` 中的 `IsVercel` 改为 `true`：

```json
"IsVercel": true
```

### 1.2 需要的环境变量

| 变量 | 必填 | 说明 |
|------|------|------|
| `MONGODB_SERV` | ✅ | MongoDB 连接串（推荐 [MongoDB Atlas](https://www.mongodb.com/atlas) 免费层） |
| `MONGODB_NAME` | ❌ | 数据库名称，为空默认 `eb_site` |
| `SITE_KEY` | ✅ | 网站密钥，越长越安全，可用随机字符串 |
| `THEME` | ❌ | 主题名称，不填则用 `conf/setting.json` 中的值 |

---

## 二、一键部署

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fyibo7%2Febsite_cms.git&env=SITE_KEY,MONGODB_SERV,MONGODB_NAME&project-name=ebsite_cms&repository-name=ebsite_cms)

点击上方按钮，按提示操作：

1. 关联你的 GitHub 账号，选择仓库
2. 在环境变量页面填入上面的变量
3. 点击 Deploy 等待部署完成

> 如果希望保留 `setting.json` 中的默认值，可将 `MONGODB_SERV` 或 `MONGODB_NAME` 留空，系统会使用配置文件中的值。

## 三、初始化数据

打开后台登录页面（首次访问会自动初始化默认数据）：

```
https://你的域名/admin/login_ad
```

初始化完成后使用以下账号登录：

| 用户名 | 密码 |
|--------|------|
| `admin` | `ebsite111111` |

## 四、部署区域

| 区域 | 代码 | 地理位置 |
|------|------|----------|
| 香港 | `hkg1` | Hong Kong |
| 日本 | `nrt1` | Tokyo（成田） |
| 新加坡 | `sin1` | Singapore |
| 韩国 | `icn1` | Incheon（首尔） |

修改 `vercel.json` 中的 `regions` 可更改部署区域：

```json
{
  "regions": ["sin1"]
}
```

> 免费版只能选择一个区域，付费版可添加多个。

---

## 五、使用 Redis 缓存（可选）

Vercel 上无法使用内存缓存，默认使用 MongoDB 做缓存。如需更高性能，可改用 Redis：

1. 部署一个 Redis 实例（推荐 [Upstash](https://upstash.com) 免费层）
2. 修改 `conf/setting.json` 中的 `REDIS_SERV` 连接串

---

## 六、注意事项

- 频繁推送代码到 GitHub 可能导致 Vercel 自动部署过于频繁
- Vercel 免费版有每月带宽和函数执行时长限制，注意监控用量
- 环境变量修改后需重新部署才能生效
