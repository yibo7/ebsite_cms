# 在 Docker 上部署（推荐生产环境）

Docker 部署是最推荐的生产运行方式，通过 uwsgi + gevent 提供高性能并发支持。

> 部署前建议将 `conf/setting.json` 中的 `IsVercel` 设为 `false`，以启用内存缓存获得更高性能。

---

## 一、前提条件

确保已安装：

- [Docker](https://docs.docker.com/get-docker/)
- [Docker Compose](https://docs.docker.com/compose/install/)（通常随 Docker Desktop 一起安装）

---

## 二、快速部署

### 2.1 打包项目

将项目目录打包为 `ebsite.tar.gz`，上传到 Linux 服务器后解压：

```bash
tar -xzvf ebsite.tar.gz
cd ebsite_cms
```

### 2.2 修改配置

编辑 `conf/setting.json`，至少修改以下项：

| 配置项 | 说明 |
|--------|------|
| `MONGODB_SERV` | MongoDB 连接串 |
| `MONGODB_NAME` | 数据库名称 |
| `APP_KEY` | 网站密钥，建议改为随机字符串 |
| `IsDebug` | 生产环境设为 `false` |
| `Port` | 应用监听端口，**需与 docker-compose 映射端口一致**（默认 `8066`） |

### 2.3 构建并启动

```bash
docker-compose up -d
```

### 2.4 访问页面

| 页面 | 地址 |
|------|------|
| 首页 | `http://服务器IP:端口` |
| 后台登录 | `http://服务器IP:端口/admin/login_ad`（首次访问自动初始化数据） |

## 三、项目结构说明

### Dockerfile

```dockerfile
FROM python:3.12.5
WORKDIR /app
COPY ./ /app
RUN pip install -i https://pypi.tuna.tsinghua.edu.cn/simple --no-cache-dir -r requirements.txt
CMD ["uwsgi", "--ini", "uwsgi.ini"]
```

- 使用 Python 3.12 基础镜像
- 默认采用清华镜像源加速 pip 安装
- 默认使用 **uwsgi** 启动（配置见 `uwsgi.ini`）

### docker-compose.yml

```yaml
services:
  flask-app:
    container_name: ebsite
    build:
      context: .
      dockerfile: Dockerfile
    restart: always
    networks:
      - 1panel-network
    volumes:
      - ./:/app       # 挂载当前目录，修改代码即时生效
    ports:
      - "8066:8066"   # 主机端口:容器端口
```

> `volumes` 将宿主机当前目录挂载到容器 `/app`，**修改宿主机代码后容器自动生效**，无需重新构建。

### uwsgi.ini

```ini
[uwsgi]
lazy-apps = true
http = :8066
gevent = 100
master = true
wsgi-file = index.py
callable = app
processes = 4
threads = 2
stats = 127.0.0.1:8067
```

## 四、可选配置

### 4.1 修改运行端口

1. 修改 `conf/setting.json` 中的 `Port`（如改为 `8080`）
2. 修改 `docker-compose.yml` 中的 `ports` 映射（如 `"80:8080"`）

### 4.2 更换 Python 镜像源

如果默认的清华源不适用，修改 `Dockerfile` 中的 pip 安装命令：

```dockerfile
# 默认（清华源）
RUN pip install -i https://pypi.tuna.tsinghua.edu.cn/simple --no-cache-dir -r requirements.txt

# 改为官方源
RUN pip install -r requirements.txt
```

### 4.3 更换 Web 服务器

项目提供两种运行方式：

#### 方式一：uwsgi（默认，推荐）

```dockerfile
CMD ["uwsgi", "--ini", "uwsgi.ini"]
```

需要确保 `requirements.txt` 中包含 `uwsgi`，如没有则手动添加。

#### 方式二：gevent（内嵌服务器）

```dockerfile
CMD python index.py
```

`index.py` 在生产模式（`IsDebug: false`）下会自动启动 gevent WSGI 服务器，无需 uwsgi。

两者性能差异不大，uwsgi 在进程管理和配置灵活性上更有优势。

### 4.4 自定义网络

默认使用 `1panel-network`（方便与 1Panel 面板上的数据库通信）。
如需修改，编辑 `docker-compose.yml` 中的 `networks` 节点：

```yaml
networks:
  my-network:
    driver: bridge
```

## 五、后期维护

由于 `docker-compose.yml` 已将当前目录挂载到容器，**直接修改宿主机上的项目文件即可**，
修改即时生效。如需重新构建镜像（如修改了 Dockerfile 或 requirements.txt）：

```bash
docker-compose down
docker-compose up -d --build
```
