# 在 Windows 上运行

适合本地开发调试或小规模自用。生产环境建议使用 Docker 部署。

> 部署前建议将 `conf/setting.json` 中的 `IsVercel` 设为 `false`，以启用内存缓存。

---

## 一、安装 Python

### 1.1 版本要求

Python **3.9 以上**，推荐 3.12 或更高版本。

### 1.2 下载与安装

从 [Python 官网](https://www.python.org/downloads/) 下载安装包。

**安装时务必勾选 ✅ Add Python to PATH**，否则后续命令会找不到 python。

安装完成后在命令行验证：

```cmd
python --version
```

---

## 二、安装 MongoDB

### 2.1 下载

从 [MongoDB 社区版下载页](https://www.mongodb.com/try/download/community) 下载 Windows MSI 安装包。

### 2.2 安装

安装时选择 **Complete** 模式，勾选 **Install MongoDB as a Service**。

### 2.3 验证

```cmd
mongosh
```

看到 `test>` 提示符即表示安装成功（输入 `exit` 退出）。

> 如需使用积分、订单等事务功能，MongoDB 需以 **单节点副本集** 模式启动。
> 请参考《事务相关的配置问题》文档进行配置。

---

## 三、配置项目

### 3.1 修改配置文件

打开 `conf/setting.json`，至少修改以下项：

```json
{
    "MONGODB_SERV": "mongodb://127.0.0.1:27017",
    "MONGODB_NAME": "eb_site",
    "APP_KEY": "替换为一个随机字符串",
    "IsDebug": true,
    "IsVercel": false,
    "Port": 8066
}
```

| 配置项 | 说明 |
|--------|------|
| `MONGODB_SERV` | MongoDB 连接串，本地默认如上 |
| `MONGODB_NAME` | 数据库名称 |
| `APP_KEY` | 网站密钥，建议改为随机字符串 |
| `IsDebug` | `true` 为调试模式（热重载），`false` 为生产模式 |
| `IsVercel` | Windows 本地运行设为 `false` |
| `Port` | 应用监听端口 |

## 四、安装依赖

### 4.1 创建虚拟环境（推荐）

```cmd
python -m venv venv
venv\Scripts\activate
```

激活后命令行前会出现 `(venv)` 标识。

### 4.2 安装依赖

```cmd
pip install -r requirements.txt
```

> ⚠️ `requirements.txt` 中可能包含 `uwsgi`，**Windows 无法安装 uwsgi**。
> 如果安装报错，先删除 `requirements.txt` 中的 `uwsgi` 行，或直接忽略该错误（不影响本地运行）。

---

## 五、运行项目

```cmd
python index.py
```

默认访问地址：

| 页面 | 地址 |
|------|------|
| 首页 | `http://127.0.0.1:8066` |
| 后台登录 | `http://127.0.0.1:8066/admin/login_ad`（首次访问自动初始化数据） |

如需更改端口，修改 `conf/setting.json` 中的 `Port` 即可。

---

## 六、生产模式运行

将 `conf/setting.json` 中的 `IsDebug` 设为 `false`，项目将使用 **gevent** 高性能服务器运行：

```json
"IsDebug": false
```

两种模式对比：

| 模式 | `IsDebug` | 服务器 | 特点 |
|------|-----------|--------|------|
| 调试模式 | `true` | Flask 内置服务器 | 代码修改后自动重载，适合开发 |
| 生产模式 | `false` | Gevent WSGI 服务器 | 更高并发性能，适合正式运行 |

## 七、常见问题

### Q：`pip install` 报错 `Microsoft Visual C++ 14.0 is required`？

部分依赖包需要 C++ 编译环境。下载安装 [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) 即可。

### Q：`python index.py` 启动后访问不到？

检查 Windows 防火墙是否阻止了端口，或尝试将 `conf/setting.json` 中的 `Port` 改为其他值（如 `8080`）。

### Q：如何停止运行？

在命令行中按 `Ctrl + C`。
