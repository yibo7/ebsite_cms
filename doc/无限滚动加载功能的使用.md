# 无限滚动加载功能（Infinite Scroll）

## 概述

本主题内置了基于 [Infinite Scroll](https://infinite-scroll.com/) 插件的无限滚动加载功能，支持两种加载模式：

| 阶段 | 加载方式 | 说明 |
|---|---|---|
| 第 1～2 页 | 自动滚动加载 | 用户向下滚动页面时自动加载下一页 |
| 第 3 页起 | 手动点击加载 | 自动加载关闭，显示 **LoadMore...** 按钮，用户点击后加载 |

这种"先自动、后手动"的设计避免了持续滚动时页面过深导致误操作，同时保证首屏体验流畅。

这些脚本已内置在主题的 `base_site.html` 中，无需手动添加：


如未使用 `base_site.html`，需自行引入上述依赖。

## 使用步骤

### 第一步：给列表容器和项目添加约定的 CSS 类

JS 通过 CSS 类名定位容器和项目，需要在模板中添加两个类：

```html
<!-- 容器：补充 eb-list-box 类 -->
<div class="your-grid-class eb-list-box">

  <!-- 每个项目：补充 eb-list-item 类 -->
  <a href="..." class="your-item-class eb-list-item">...</a>
  <a href="..." class="your-item-class eb-list-item">...</a>
  <a href="..." class="your-item-class eb-list-item">...</a>

</div>
```

> 原有的样式类（如 `product-grid`、`product-card`）**保留不变**，只需**额外加上** `eb-list-box` / `eb-list-item` 即可。

### 第二步：包含 `loading_more.html` 模板片段

在列表容器**闭合之后**、分页器**之前**，用 `{% include %}` 引入：

```html
<div class="your-grid-class eb-list-box">
  <!-- 列表项目循环 -->
</div>

{% include 'includes/loading_more.html' %}

<!-- 分页器（必须保留，作为 Infinite Scroll 的数据源） -->
{% if data_list %}
  <div>{{ pager }}</div>
{% endif %}
```

`loading_more.html` 会自动加载其配套的 JS 脚本，无需额外引用。

### 第三步：（必须）保留 `{{ pager }}` 分页器

Infinite Scroll 需要从分页器中读取下一页的 URL，因此分页器**必须保留在 DOM 中**。JS 初始化后会自动隐藏分页器的视觉效果，用户看不到它。

分页器由 `MvcPager`（`eb_utils/mvc_pager.py`）生成，它会产生类似这样的 HTML：

```html
<ul class='pagination'>
  <li class='page-item'><a class='page-link' href='...'>上一页</a></li>
  <li class='page-item active'><a class='page-link' href='#'>1</a></li>
  <li class='page-item'><a class='page-link' href='...'>2</a></li>
  ...
  <li class='page-item'><a class='page-link next-page' href='...'>下一页</a></li>
</ul>
```

JS 依赖其中的：
- `ul.pagination` — 判断是否有分页（多页数据）
- `a.next-page` — 获取下一页 URL

### 第四步：处理无数据的情况

当列表无数据时（`{% else %}` 分支），应在容器内显示空状态提示，`loading_more.html` 和分页器应在该分支**之外**：

```html
<div class="your-grid-class eb-list-box">
  {% if data_list %}
    {% for item in data_list %}
      <a href="..." class="your-item-class eb-list-item">...</a>
    {% endfor %}
  {% else %}
    <div class="empty-state">暂无数据</div>
  {% endif %}
</div>

{% include 'includes/loading_more.html' %}

{% if data_list %}
  <div>{{ pager }}</div>
{% endif %}
```

当只有一页数据时，`{{ pager }}` 输出空字符串，`loading_more.js` 检测到无 `.pagination` 元素，会自动隐藏整个 `load_more_box`。

## 完整示例

来自 `list_shop.html` 的简化结构：

```html
{% extends 'base_site.html' %}

{% block content %}

  <!-- 内容区 -->
  <main class="content-area">

    <!-- 产品网格（容器 + 循环） -->
    <div class="product-grid eb-list-box">
      {% if data_list %}
      {% for item in data_list %}
      <a href="{{ item.get_url() }}" class="product-card eb-list-item">
        {{ item.title }}
      </a>
      {% endfor %}
      {% else %}
      <div class="empty-state">暂无数据</div>
      {% endif %}
    </div>

    <!-- 加载更多（自包含模板+JS） -->
    {% include 'includes/loading_more.html' %}

    <!-- 分页器（无限滚动的数据源） -->
    {% if data_list %}
    <div>{{ pager }}</div>
    {% endif %}

  </main>

{% endblock %}
```

## 补充：在不支持的主题中使用

如果要在**其他主题**中使用此功能：

1. 将 `themes/eb_shop/templates/includes/loading_more.html` 复制到目标主题的 `templates/includes/` 下
2. 将 `themes/eb_shop/static/js/loading_more.js` 复制到目标主题的 `static/js/` 下
3. 确保 `base.html` 中加载了：
   - jQuery（3.x）
   - `/js/comm.js`（需包含 `In` 模块加载器及 `infinitescroll` 模块注册）
4. 按上述步骤改造列表模板

## 原理说明

```
list_shop.html
  │
  ├── .eb-list-box（商品容器）
  │     └── .eb-list-item（商品卡片 × N）
  │
  ├── includes/loading_more.html
  │     ├── .load-more（LoadMore 按钮）
  │     ├── .page-load-status（状态区域：加载动画 / 结束提示 / 错误提示）
  │     └── loading_more.js（初始化 Infinite Scroll）
  │
  └── {{ pager }} → <ul class='pagination'>
        └── a.next-page（下一页链接，被 Infinite Scroll 读取）
```

`loading_more.js` 的执行时机：

1. 页面解析到 `<script src="/js/loading_more.js">` 时，注册 `DOMContentLoaded` 回调
2. HTML 解析完毕 → `defer` 脚本（jQuery、comm.js）执行完毕
3. `DOMContentLoaded` 触发 → `loading_more.js` 的回调执行
4. 回调中检测 `.pagination` 是否存在：

   - **有分页（多页）** → 通过 `In.ready('infinitescroll')` 初始化 Infinite Scroll → 前 2 页自动加载 → 之后显示 LoadMore 按钮供手动点击
   - **无分页（单页）** → 直接隐藏 `load_more_box`

## 常见问题

**Q：分页器显示出来了，没有被隐藏？**

检查 `loading_more.js` 是否被正确加载。打开浏览器控制台，查看是否有 `ul.pagination` 被隐藏。也可以确认 `extensions.js` 中是否已移除旧的无限滚动代码（避免重复初始化）。

**Q：LoadMore 按钮不显示？**

如果只有 1 页数据（`{{ pager }}` 为空），`loading_more.js` 会自动隐藏整个 `load_more_box`，这是正常行为。有 2 页以上数据时才显示。

**Q：新产品卡片加载后样式错乱？**

Infinite Scroll 加载的是完整 HTML 片段，确保后端输出的列表页片段中，只有 `eb-list-item` 部分，不包含外层容器、`loading_more.html` 和分页器。可以通过判断 `request.headers.get('X-Requested-With')` 是否为 `'XMLHttpRequest'` 来区分 AJAX 请求与正常访问，输出不同的模板片段。

**Q：筛选/排序功能与新加载的卡片不兼容？**

客户端筛选（如 `products.js`）的 `allProducts` 数组只在页面加载时收集一次。Infinite Scroll 新增的卡片需要手动加入筛选范围。这是一个已知限制，如有需要可以扩展 `products.js` 在每次加载完成后重新收集数据。
